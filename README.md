# JavaScript Practicals 🚀

A collection of JavaScript practical experiments covering core concepts of client-side scripting using HTML and JavaScript.

## 📁 Experiments

| File | Description |
|------|-------------|
| `exp1_basic.html` | Basic JavaScript — variables, data types, and output |
| `exp2_array.html` | Arrays — creation, manipulation, and iteration |
| `exp3__string_operations.html` | String operations — methods and manipulation |
| `exp4_form_elements.html` | Form elements — input types and DOM interaction |
| `exp5_form_events.html` | Form events — handling user interactions |
| `exp6_intrinsic_functions.html` | Intrinsic functions — built-in JS functions |
| `exp7_cookies.html` | Cookies — reading, writing, and deleting cookies |
| `exp8_Window_positioning.html` | Window positioning — controlling browser windows |
| `exp9_regular_expressions.html` | Regular expressions — pattern matching with RegEx |
| `exp10_rollovereffect.html` | Rollover effects — image/element hover effects |
| `exp11_menus.html` | Menus — dynamic navigation menus using JS |
| `exp12_statusbar.html` | Status bar — manipulating the browser status bar |

## 🛠️ Tech Stack

- **HTML5** — Structure and layout
- **JavaScript (Vanilla)** — Client-side scripting
- No frameworks, no libraries — pure JS!

## 🚀 How to Run

Simply open any `.html` file in your browser:

```bash
# Clone the repo
git clone https://github.com/Sharvinkolhe/JS__PRACTICAL.git

# Navigate to the folder
cd JS__PRACTICAL

# Open any experiment in your browser
start exp1_basic.html
```
